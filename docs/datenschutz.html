4. Betrieb des RAG-Prototypen (Anwendung)

Der auf dieser Website vorgestellte Chatbot-Prototyp läuft auf einer getrennten Server-Infrastruktur und ist derzeit nur für einen geschlossenen Nutzerkreis zu Test- und Evaluationszwecken zugänglich. Auf dieser öffentlichen Projektseite werden weder Originaldokumente noch Fotografien oder Personendaten aus dem Museumsbestand veröffentlicht.

  • Hosting und Datenbank: Die Anwendung, die Vektordatenbank (Qdrant) und die Mediendateien werden in Docker-Containern auf einem virtuellen Server bei Hostinger (Serverstandort in der Europäischen Union) betrieben.
  • Sprachmodell und Vektorisierung: Zur Analyse von Suchanfragen, zur Relevanzbewertung (Reranking) und zur Formulierung der Antworten nutzt das System die Programmierschnittstelle (API) von OpenAI (OpenAI, L.L.C., USA; eingesetzte Modelle: gpt-4o-mini und text-embedding-3-small). Dabei werden der Fragetext sowie die relevanten Textauszüge aus dem Archivbestand an OpenAI übermittelt. Über die API übermittelte Daten werden von OpenAI gemäss deren API-Richtlinien nicht zum Training von Modellen verwendet. Siehe die Datenschutzerklärung von OpenAI.
  • Telegram-Anbindung: Bei Nutzung des optionalen Telegram-Kanals werden Nachrichten über die Infrastruktur von Telegram (Telegram Messenger Inc.) an den abgesicherten Webhook des Servers übertragen.
  • Anonymes Betriebsprotokoll: Zur Qualitätssicherung und für das Rate-Limiting speichert das System lokal auf dem Server in einer SQLite-Datenbank den Zeitpunkt, den Kanal (Web oder Telegram), die eingegebene Sachfrage, die Antwortzeit, die Trefferanzahl sowie optionale Daumen-Bewertungen. IP-Adressen, Klarnamen oder Telegram-Benutzernamen werden nicht gespeichert; Sitzungen werden nur als einweg-gehashte Prüfwerte (SHA-256 mit Salt) geführt.
  • Keine Weitergabe: Es erfolgt kein Verkauf von Daten und keine Nutzung zu Werbezwecken.
