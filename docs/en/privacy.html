4. Operation of the RAG prototype (application)

The chatbot prototype presented on this website runs on separate server infrastructure and is currently accessible only to a closed user group for testing and evaluation. Neither original documents nor photographs or personal data from the museum's holdings are published on this public project site.

  • Hosting and database: The application, vector database (Qdrant) and media files run in Docker containers on a virtual server hosted by Hostinger (server location in the European Union).
  • Language model and embeddings: To analyse search queries, score relevance (reranking) and synthesise answers, the system uses the API of OpenAI (OpenAI, L.L.C., USA; models used: gpt-4o-mini and text-embedding-3-small). The query text and relevant text excerpts from the archive are transmitted to OpenAI. Under OpenAI's API data usage policies, data submitted via the API is not used to train models. See the OpenAI privacy policy.
  • Telegram integration: When using the optional Telegram channel, messages are transmitted via Telegram's infrastructure (Telegram Messenger Inc.) to the server's authenticated webhook.
  • Pseudonymous operational log: For quality assurance and rate limiting, the system stores timestamp, channel (web or Telegram), query text, response latency, hit count and optional thumb ratings locally on the server in a SQLite database. IP addresses and Telegram usernames are not stored; sessions are recorded only as one-way salted hashes (SHA-256). Since a question itself may contain names or addresses, the log is pseudonymous rather than fully anonymous. After 90 days, the question text, any names it contains, comments and the session hash are deleted automatically; only anonymous statistics remain (timestamp, channel, hit count, response time, rating). At the start, the chat states that the answers are generated by an AI language model.
  • No sharing: Data is never sold or used for advertising.
