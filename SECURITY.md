# Sicherheit

## Sicherheitslücke melden

Bitte melden Sie Sicherheitslücken nicht über ein öffentliches Issue, sondern vertraulich über die Funktion «Report a vulnerability» im Reiter **Security** dieses Repositorys oder per E-Mail an beat.b.hutter@gmail.com.

Please do not report security issues through public issues. Use "Report a vulnerability" in the **Security** tab of this repository or write to beat.b.hutter@gmail.com.

## Geltungsbereich

Dieses Repository enthält Code und Dokumentation, aber keine Zugangsdaten und keine Daten des Museums. Hinweise auf versehentlich veröffentlichte Schlüssel, Passwörter oder Personendaten sind trotzdem willkommen und werden vorrangig behandelt.
